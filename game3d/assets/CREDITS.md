# Créditos dos recursos

Todos os recursos desta pasta são de domínio público (CC0 1.0), usados sem alteração de licença.

## Personagens e armas — KayKit, por Kay Lousberg (www.kaylousberg.com)
- **KayKit Adventurers Character Pack 1.0** — `knight.glb` (jogador), `barbarian.glb` (Brutamontes), `rogue.glb` (Assassino, a partir de `Rogue_Hooded`)
  https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
- **KayKit Skeletons Character Pack 1.0** — `skeleton_warrior.glb` (Soldado), `skeleton_rogue.glb` (Arqueiro), `skeleton_blade.glb`, `skeleton_shield.glb`, `skeleton_crossbow.glb`
  https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0

Licença: Creative Commons Zero (CC0) — http://creativecommons.org/publicdomain/zero/1.0/

Os arquivos foram otimizados para a web com glTF-Transform: só as animações e armas usadas no jogo,
apenas rotações dos ossos (+ translação do quadril) e compressão meshopt.
